# 📦 Система управления складом (Склад товаров)

Веб-приложение для управления товарами на складе, включающее каталог, корзину, систему авторизации пользователей и панель администратора. Проект написан на чистом PHP (без фреймворков) с использованием MySQL.

## ✨ Возможности

### Для всех пользователей
- 🔐 Регистрация и вход (пароли хешируются)
- 🛒 Просмотр каталога товаров с фильтром по категориям
- 🔍 Детальная карточка товара
- 🛍️ Добавление товаров в корзину (сессия)
- 📝 Оформление заказа с указанием количества
- 👤 Личный кабинет с историей заказов

### Для администратора (id = 1)
- 👑 Специальная панель администратора
- 👥 Просмотр заказов всех пользователей
- 🔎 Фильтрация заказов по конкретному пользователю
- 📊 Общая статистика (сумма, количество заказов)

### Управление складом
- ➕ Добавление товаров (название, категория, цена, кол-во, срок годности)
- ✏️ Редактирование цены и количества товара
- ❌ Удаление товаров
- 📁 Управление категориями (добавление / просмотр)

## 🧰 Стек технологий

- **Backend:** PHP 7/8 (нативный)
- **Database:** MySQL
- **Frontend:** HTML, CSS (базовая встроенная стилизация)
- **Сервер:** Apache/Nginx (для `.htaccess` не используется)
- **Дополнительно:** Сессии, хеширование паролей (bcrypt)

## 🗄️ Структура базы данных

Проект предполагает наличие следующих таблиц:

### Таблица `users`
| Поле       | Тип          | Описание                        |
|------------|--------------|---------------------------------|
| id         | INT (PK)     | ID пользователя                 |
| login      | VARCHAR(50)  | Логин (уникальный)              |
| hash       | VARCHAR(255) | Хеш пароля (bcrypt)             |
| name       | VARCHAR(100) | Имя пользователя                |
| age        | INT (опц.)   | Возраст (задел на будущее)      |
| salary     | DECIMAL (опц.)| Зарплата (задел на будущее)     |
| photo      | VARCHAR(255) | Фото (задел на будущее)         |

### Таблица `categories`
| Поле       | Тип          | Описание                        |
|------------|--------------|---------------------------------|
| id_cat     | INT (PK)     | ID категории                    |
| category   | VARCHAR(100) | Название категории              |

### Таблица `tovars`
| Поле       | Тип          | Описание                        |
|------------|--------------|---------------------------------|
| id         | INT (PK)     | ID товара                       |
| name       | VARCHAR(200) | Наименование товара             |
| id_cat     | INT (FK)     | Ссылка на `categories.id_cat`   |
| cena       | DECIMAL(10,2)| Цена                            |
| kol        | INT          | Количество на складе            |
| srok       | DATE         | Срок годности                   |

### Таблица `orders`
| Поле       | Тип          | Описание                        |
|------------|--------------|---------------------------------|
| id_order   | INT          | Номер заказа (timestamp)        |
| id_user    | INT (FK)     | ID пользователя (`users.id`)    |
| id_tovar   | INT (FK)     | ID товара (`tovars.id`)         |
| quantity   | INT          | Количество в заказе             |
| cost       | DECIMAL(10,2)| Цена на момент заказа           |
| datatime   | DATETIME     | Дата и время оформления         |

> **Важно:** Внешние ключи в коде не прописаны явно, но логически они используются. При развертывании создайте таблицы вручную.
